This report displays several plots per neuron, NOTE: the max value is reported as (a,b) with a on the y axis. In the final plot, the preactivation heatmap is remapped. For each original (a, b) pair (with a, b in [0, p-1]), the new coordinates are computed as: new_a = (freq * a) % p and new_b = (freq * b) % p, where p is the number of a-values (or b-values).
